## 定位证据

旧导出把所有代码节点写死为 14px，没有代码字号设置；正文追加完整长 URL，导致手机中占用多行。默认 scroll 使长命令需要横滑。

只读获取的问题草稿中，Bash 标题已成为无样式 p/span，代码仍为 14px；部分空格也在该草稿中丢失。后台写入前只重写图片 src，没有删除标题样式。新结构的直接 API 往返保留完整字符和样式，因此不能将旧问题归因于 API 必然删除格式；后台编辑或手动粘贴仍是不同的处理路径。
