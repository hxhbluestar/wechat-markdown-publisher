# 草稿同步和 Markdown 导入验收

版本：`2026.10.22-workflow.5`。

本次调整的目标是减少常规操作的中间步骤：建议检查不阻止同步到草稿箱；Markdown 文件直接导入。

## 行为与回归范围

- 本地建议、服务端建议及旧版 `confirm` 提醒均不要求勾选，不自动打开检查或错别字弹窗。手动校对、高亮、定位、修改和保存仍可使用。
- 超过建议数量上限时仅显示汇总；随后发现的缺图、危险 HTML 等硬错误仍可见且阻止同步。超过结构分析范围仍阻止同步。
- 同步继续要求正文、设置、素材、账号和渲染版本的一致指纹；服务器不可用、版本变化、远端覆盖冲突等继续停止当前请求。
- Markdown 主入口直接选择文件创建新稿；读取失败、保存失败、导入期间编辑或切换稿件时保护当前输入；重复文件选择不会并发创建重复稿件。
- ZIP 配图包、DOCX、HTML 转换和 ROCm 博客入口保留。

## 自动化结果

- Node/DOM：320 项通过，包含导入、校对、自动预检、建议上限及版本一致性回归。
- Python：283 项通过，1 项因主机不允许创建符号链接而跳过。覆盖服务端预检、任务、HTTP API、素材、保存、恢复及部署边界。
- HTTP 回归显式加载当前源码，避免嵌入式 Python 的固定导入路径误测已安装的旧模块。
- 隔离真实编辑器：26 项完整流程断言通过，包含建议稿确实发出同步请求、空确认清单、有效指纹、缺图不发起第二次同步，以及导入前保存顺序。
- 整页布局：14 种窗口尺寸、323 项断言通过，覆盖 3840×1958 至 390×500 的编辑、预览、滚动和同步弹窗。
- 正常引用上标、下标允许零行高，避免把引用编号误报为正文重叠；父段落、块状元素低行高和真实固定高度裁切仍有回归检查。

本次流程验收使用临时稿件和合成账号，隔离服务器拒绝实际微信外写。它验证编辑器能发起同步请求及硬错误会拦截，不代表真实公众号发布或移动端微信渲染验收。
