# 编辑器布局与同步窗口

版本：`2026.10.18-layout.1`。

编辑区和预览区各占一列并使用完整的工作区高度。旧发布面板已移出编辑网格，避免宽屏时产生隐式第二行。顶部保留创作工具、保存、错别字与同步入口，直接公开发布位于同步窗口的高级操作中，仍默认关闭。

“排版与设备”“大纲与局部微调”按需展开，一次打开一个，浮在预览上方。展开时不挤压文章；选项较多时在面板内滚动，面板高度跟随预览可用空间。版式、配色与同步滚动开关仍可直接使用。

点击“同步到公众号”先核对目标账号、文章检查结果、网络状态和既有同步记录。打开或关闭窗口不保存文章、不新建同步任务。窗口底部的确认操作继续走原来的校对、服务器检查、同步任务和远端核对流程；详细检查、任务进度及账号管理会关闭当前窗口再接续打开，避免层层叠加。Esc 可关闭窗口，焦点返回同步入口。

900px 及以下改为编辑/预览切换。未显示的面板保留几何尺寸供滚动映射使用，同时从可见界面与键盘导航中隐藏。大纲、校对及问题定位会自动显示对应的编辑面板；账号问题打开同步窗口，封面问题打开素材面板。

回归覆盖 Node DOM 交互、可重复构建、Python 隔离部署及浏览器整页布局。整页测试从 390px 到 3840px，包括 390×500 和 1366×600 的短窗口，检查双栏高度、页面溢出、设置面板、设备选择、同步弹窗、标题可见性、焦点恢复和窄屏定位/同步滚动。使用临时合成稿件、空账号库，并阻止测试环境向微信执行同步写入。

本次结果：Node 285 项通过；Python 261 项运行成功，含 1 项因 Windows 权限跳过；整页浏览器 14 种尺寸、323 项检查通过。独立代码复核后未留下 Critical 或 Important 问题。

复现浏览器测试：先 `npm ci --ignore-scripts`、`npm run build`，再运行 `python tests/serve-editor-layout.py`，打开 `http://127.0.0.1:19020/tests/editor-layout-browser.html`。关闭测试进程即可结束。只允许该独立测试服务被同源验收页面嵌入，生产服务的禁止嵌入策略保持不变。

这些结果属于浏览器界面验收，不代表已经向实际公众号同步或完成微信真机排版验收。
