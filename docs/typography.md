# 文章排版

编辑器提供技术手册、纸感期刊、极简墨色，以及 AMD 实验室风格的曜石青、深海青、青绿实验室六套版式，覆盖技术长文中的标题、正文、代码、图片说明、引用和表格。新建稿件默认使用技术手册；已有稿件继续加载原先保存的版式。

## 六套版式

| 版式 | 标识 | 阅读特点 | 切换版式时的推荐组合 |
| --- | --- | --- | --- |
| 技术手册 | `technical` | 黑体正文、清晰的标题层级、深色代码区，适合命令和参数较多的文章 | 17px 正文、代码横向滚动、表格自动适配 |
| 纸感期刊 | `journal` | 宋体正文、暖色纸感背景、较宽松的行距，适合解释与叙述 | 17px 正文、代码阅读换行、简单表格分行卡片 |
| 极简墨色 | `minimal` | 黑体正文、克制的装饰与浅色代码区，适合简洁教程 | 16px 正文、代码阅读换行、表格自动适配 |
| 曜石青 | `obsidian` | 黑底配青色强调，适合 AMD 实验室风格的技术文章 | 17px 正文、代码阅读换行、表格自动适配 |
| 深海青 | `deepsea` | 浅青纸张配深蓝绿色代码区，兼顾正文与命令阅读 | 17px 正文、代码阅读换行、表格自动适配 |
| 青绿实验室 | `teal` | 白纸配浅青代码区，适合明亮、清晰的实验步骤 | 17px 正文、代码阅读换行、表格自动适配 |

切换版式会加载该版式的推荐组合，随后可以单独调整六项排版设置。默认配色保留各版式的原设计；其他配色作用于标题强调、链接和相关边线，纸张与代码语法配色由版式控制。

## 六项排版设置

| 设置 | 可选值 | 用途 |
| --- | --- | --- |
| 正文字体 | 随版式、系统黑体、阅读宋体 | 随版式时，纸感期刊使用宋体，其余新主题使用黑体；实际字体取决于手机或电脑已安装的字体 |
| 正文字号 | 15、16、17、18px | 调整正文和列表文字；代码块继续使用等宽字体及独立字号 |
| 图片说明字号 | 12、13、14、15、16px，新主题默认 12px | 调整图片下方说明文字，最低 12px；旧三版式默认保留约 13px 的原有图注 |
| 表格字号 | 12、13、14、15、16px，新主题默认 13px | 调整表格及分行卡片内文字，最低 12px；旧三版式默认保留 16px，宽表格通过滚动或卡片显示完整内容 |
| 代码长行 | 横向滚动、阅读换行 | 横向滚动保留长行形态；阅读换行适合手机阅读，不改写 Markdown 中的原始代码 |
| 表格呈现 | 自动适配、保留横滑、分行卡片 | 简单短表格可直接适配；宽表格可横向滚动；简单数据表可按每行生成带字段名称的卡片 |

代码块显示语言标记，并为支持的语言应用语法高亮，包括新增的 PowerShell 语法模块。未知语言按纯文本显示。

上表的“新主题”指技术手册、纸感期刊、极简墨色、曜石青、深海青、青绿实验室。旧 `grace`、`default`、`simple` 的图片说明默认元数据为 13，保留原版式约 13px 的图注；表格默认元数据为 16。旧版式中将任一项选为 12px 都会明确应用 12px，并形成新的稿件 revision。

## 图片说明与表格

紧跟图片的 `*图 1：实验室架构。*`、`**Figure 1: Laboratory layout.**` 等编号说明，也会在预览和发布 HTML 中识别为图注，跟随图片说明字号。Markdown 原文保持不变，普通正文段落不会合并为图注。

图片说明优先取 Markdown 图片的显式 `title`，没有 `title` 时使用描述性的 `alt`。文件名形式的 `alt` 和图片路径不自动生成说明。例如：

```markdown
![多卡互联拓扑](images/topology.png "图 1：多卡互联拓扑")
```

上述图片的说明为“图 1：多卡互联拓扑”。`![topology.png](images/topology.png)` 不会把文件名显示成图片说明。没有说明文本时不额外生成占位文字。

宽表格保留全部列和单元格内容，超出可读宽度时在表格区域内横向滚动；分行卡片把简单表格的每行展开为带字段名称的记录，适合窄屏阅读。自动适配可让单元格文字换行，长字符串也应保持可查看，不用省略号或裁切隐藏内容。合并单元格、复杂表头等结构保留为可横滑表格，不强行转换为卡片。

## 手机宽度预览

预览可切换 320、375、430px，默认 375px，用来检查标题换行、代码长行、图片说明和表格宽度。该选项仅改变当前预览宽度，不写入稿件排版元数据，也不锁定最终文章宽度。切换字号或版式后，建议至少检查一次 320px 和 430px 的呈现；宽表格需要检查左右滑动能否读到最后一列，卡片需要检查长字段和多行内容。

排版同时用于本地预览、导出和同步时的 HTML。本地浏览器预览与自动测试不代表已完成微信真机验证；微信客户端会清理部分 HTML/CSS，横向滚动和具体字体的呈现也可能因客户端而异。同步到草稿箱后仍应在实际微信客户端检查窄屏和长表格。

## 兼容范围

- 支持 Markdown 标题、段落、行内代码、代码块、列表、普通引用、链接、图片和表格；提示型引用可使用 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 标记。
- 分行卡片适用于结构规则的简单表格。合并单元格、多行表头、嵌套表格、表尾或各行列数不一致时，保留表格并采用横滑，避免改变单元格关系。
- 旧稿件明确保存的 `grace`、`default`、`simple` 主题继续可用。原有四项均为随版式字体、16px、代码横滑、表格自动适配，且新增图片说明/表格字号为其默认的 13/16 时，保留原有旧主题处理与历史 revision。
- 已部署的四字段记录会按主题补上默认元数据：旧三版式为图片说明 13、表格 16；`technical`、`journal`、`minimal` 为图片说明 12、表格 13。使用这些等效默认值时保持原 revision。修改新增字号会形成新 revision；恢复其主题默认值后恢复对应的历史哈希，不需要迁移或改写旧稿件文件。
- 排版设置会随稿件保存。六字段同步请求须完整，且与已保存的主题、配色和设置一致。旧四字段请求仅在新增两项均为各主题默认值时兼容，即旧三版式 13/16、新六主题 12/13；任一新增项采用其他字号时，旧请求会收到 409，避免旧客户端覆盖新设置。检查在上传素材和创建远端草稿前完成。旧主题采用全部默认排版时仍兼容缺省排版对象的旧请求。
- 设置只接受预设字体、字号、代码和表格模式，不接受任意 CSS。自定义 HTML 或自行插入的样式不在全面兼容承诺内。

维护接口共六个字段：`font_family`（`theme/sans/serif`）、`font_size`（整数 `15/16/17/18`）、`caption_font_size`（整数 `12/13/14/15/16`）、`table_font_size`（整数 `12/13/14/15/16`）、`code_wrap`（`scroll/wrap`）、`table_mode`（`auto/scroll/cards`）。新增两项对新六主题默认 `12/13`，对旧三版式默认 `13/16`。缺省元数据对新主题使用 17px 正文、代码横滑及表格自动适配；编辑器切换版式时可应用上表中的推荐组合。

本版资源入口为 `index-20261017-lab.js`，排版模块为 `typography-20261017-lab.mjs`，控件资源为 `typography-controls-20261017-lab.mjs` 与 `typography-controls-20261017-lab.css`，对应版本 `2026.10.17-lab.2`。
