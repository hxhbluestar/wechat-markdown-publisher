# 文章排版

编辑器提供技术手册、纸感期刊、极简墨色三套版式，覆盖技术长文中的标题、正文、代码、引用和表格。新建稿件默认使用技术手册；已有稿件继续加载原先保存的版式。

## 三套版式

| 版式 | 标识 | 阅读特点 | 切换版式时的推荐组合 |
| --- | --- | --- | --- |
| 技术手册 | `technical` | 黑体正文、清晰的标题层级、深色代码区，适合命令和参数较多的文章 | 17px 正文、代码横向滚动、表格自动适配 |
| 纸感期刊 | `journal` | 宋体正文、暖色纸感背景、较宽松的行距，适合解释与叙述 | 17px 正文、代码阅读换行、简单表格分行卡片 |
| 极简墨色 | `minimal` | 黑体正文、克制的装饰与浅色代码区，适合简洁教程 | 16px 正文、代码阅读换行、表格自动适配 |

切换版式会加载该版式的推荐组合，随后可以单独调整四项排版设置。默认配色保留各版式的原设计；其他配色作用于标题强调、链接和相关边线，纸张与代码语法配色由版式控制。

## 四项排版设置

| 设置 | 可选值 | 用途 |
| --- | --- | --- |
| 正文字体 | 随版式、系统黑体、阅读宋体 | 随版式时，纸感期刊使用宋体，其余新主题使用黑体；实际字体取决于手机或电脑已安装的字体 |
| 正文字号 | 15、16、17、18px | 调整正文和列表文字；代码块继续使用等宽字体及独立字号 |
| 代码长行 | 横向滚动、阅读换行 | 横向滚动保留长行形态；阅读换行适合手机阅读，不改写 Markdown 中的原始代码 |
| 表格呈现 | 自动适配、保留横滑、分行卡片 | 简单短表格可直接适配；宽表格可横向滚动；简单数据表可按每行生成带字段名称的卡片 |

代码块显示语言标记，并为支持的语言应用语法高亮，包括新增的 PowerShell 语法模块。未知语言按纯文本显示。

## 手机宽度预览

预览可切换 320、375、430px，默认 375px，用来检查标题换行、代码长行和表格宽度。该选项仅改变当前预览宽度，不写入稿件排版元数据，也不锁定最终文章宽度。切换字号或版式后，建议至少检查一次 320px 和 430px 的呈现。

排版同时用于本地预览、导出和同步时的 HTML。微信客户端会清理部分 HTML/CSS，横向滚动和具体字体的呈现也可能因客户端而异；同步到草稿箱后仍应使用微信端的预览检查。

## 兼容范围

- 支持 Markdown 标题、段落、行内代码、代码块、列表、普通引用、链接、图片和表格；提示型引用可使用 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 标记。
- 分行卡片适用于结构规则的简单表格。合并单元格、多行表头、嵌套表格、表尾或各行列数不一致时，保留表格并采用横滑，避免改变单元格关系。
- 旧稿件明确保存的 `grace`、`default`、`simple` 主题继续可用。使用随版式字体、16px、代码横滑、表格自动适配时，保留旧样式与历史 revision；修改任一排版项后形成新的 revision，恢复全部默认项后恢复等效历史哈希。
- 排版设置会随稿件保存。同步请求须与已保存的主题、配色和四项排版设置一致；过期或缺失的新排版选项会在上传素材和创建远端草稿前被拒绝。旧主题采用其默认排版时兼容旧版同步请求。
- 设置只接受预设字体、字号、代码和表格模式，不接受任意 CSS。自定义 HTML 或自行插入的样式不在全面兼容承诺内。

维护接口中的四个字段为 `font_family`（`theme/sans/serif`）、`font_size`（整数 `15/16/17/18`）、`code_wrap`（`scroll/wrap`）、`table_mode`（`auto/scroll/cards`）。缺省元数据对新主题使用 17px、代码横滑及表格自动适配；编辑器切换版式时可应用上表中的推荐组合。
