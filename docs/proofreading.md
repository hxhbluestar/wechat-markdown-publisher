# 本地离线错别字校对

打开稿件后，正文编辑区会用红色波浪线标出疑似错词，工具栏“错别字”显示建议数量。点击后可查看上下文、定位原文、逐项修改或应用勾选建议。连续标点使用待核对提示，不默认勾选。

修改后点击“保存修改”保存本地稿件；普通“保存”和 Ctrl+S 也使用同一保存流程。保存请求依次执行，等待期间的新修改仍标为未保存，切换稿件后的旧响应不会覆盖当前稿件。失败时修改保留在编辑器中，可以重试。“撤销本次修改”仅在正文仍与该次修改结果一致时可用，防止覆盖随后输入的内容；保存后撤销也需要再次保存。

“忽略此词”将该原词加入当前浏览器的本机忽略列表，可用“恢复忽略项”清空。它适合专名、引用中故意保留的错字等情况。同步前发现高置信度易错词时会打开校对面板，应用建议或确认忽略后再同步。校对不会自行保存、同步或发布文章。

## 检查范围

- 内置 228 条独立整理的常见易错词/成语规则，例如“按装→安装”“以经→已经”“再接再励→再接再厉”。不把“的/地/得”、同义词或合理用字变体批量改写。
- 检查 Markdown 正文，包含正文中的标题、链接文字和图片 alt 描述；文章设置中的独立标题、作者、摘要不在本版自动检查范围内。
- 保护围栏/缩进代码、行内代码、链接目标、图片地址、URL、路径、文件名、代码型标识符、HTML 属性及原始代码容器。常见 AI/GPU 名称保留。
- 一次最多分析前 200,000 个 UTF-16 代码单元，返回 500 条建议，面板先显示前 200 条；超出时显示范围提醒。修改后可继续检查。
- 应用建议时重新校验原文、位置、规则与选区，拒绝过期、重叠或伪造的修改。高亮仅存在于编辑器，不写入 Markdown 或公众号 HTML。

本版完全离线，不需要 AI 接口或密钥，也不向第三方发送文章。规则检查不能判断所有上下文和专名，不能保证零错字；应用前仍应核对建议，发布前通读全文。

实现与测试分别位于 `frontend/proofreading*.mjs`、`frontend/save-draft.js` 及 `tests/proofreading*.test.mjs`、`tests/draft-save.test.mjs`。保存流程作为可读片段由构建器嵌入编辑器，安装端无需额外服务。
