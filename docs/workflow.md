# 创作工作流

适用版本：2026.10.22-workflow.4。本机处理文章，不需要 AI 接口。

## 保存与恢复

编辑后闲置约 1 秒、连续输入约 2 秒安排 IndexedDB 暂存。界面区分待写入、已本机暂存和后端已保存。关页瞬间尚未完成的写入仍可能丢失；请对重要修改按保存。

创作工具提供恢复记录、正文与设置对照、历史快照和回收站。旧版恢复为新副本；多窗口冲突保留输入并允许另存。回收站提示保留 30 天，永久清理需要逐条明确确认，不自动清空。快照使用内容寻址保存原图，当前不自动回收共享历史对象。

## 导入和素材

侧栏和空白页的“导入 Markdown”直接选择 `.md` / `.markdown` 文件，读取后创建新稿，不经过转换报告或重复确认。导入前保存当前修改；读取或保存失败时保留原编辑稿。Markdown 中的本地图片仍需添加到新稿素材，缺图时同步检查会明确提示。

创作工具中的导入工作台保留单篇 Markdown 配图 ZIP、DOCX 和 HTML 转换等高级入口。这些格式先查看转换数量与警告，再确认创建新稿，原始输入与报告保存在本机。复杂合并单元格和 Word 公式可能不能等效转换，报告会提示检查。ROCm 官方博客保留专用入口。

文章包可迁移正文、安全元数据、排版覆盖、图片及派生关系；账号和同步凭据不导出。当前导入包限制 12MiB，展开限制 64MiB，单图 10MiB；这些是本地资源保护值。

图片工具显示引用、图注、尺寸、帧数和重复哈希；照片压缩、清晰图导出、GIF 兼容预设和封面裁切都另存派生图。应用正文替换前保留版本。网络图片需显式下载，只接受经过逐跳公网校验的 HTTPS 图片。原图不自动删除。

## 发布前检查与任务

点击“同步到草稿箱”后自动保存并校验当前版本。错别字、来源留空、占位文字、重复标题、潜在敏感信息及不确定的排版风险只列为建议，不要求逐项勾选，不弹窗阻止同步。可随时主动打开发布检查查看、定位，或使用错别字工具修改和保存；不会自动改写正文。敏感提示仍脱敏显示。

缺正文、缺标题、缺封面、图片缺失或损坏、账号不匹配、危险 HTML、未完成的图表转换及确定的文字裁切等硬性错误继续阻断。版本指纹、素材哈希和服务端校验继续生效，避免同步过时内容；建议检查不能替代作者对最终文章的核对。

同步冻结正文、设置、素材哈希、目标账号和渲染版本。任务显示素材、封面、草稿写入及远端核对；失败后显式重试，复用已经确认上传的素材。远端结果不明时停止自动写入，可明确查询最近草稿或输入已知标识；再次读回且与快照一致后才关联成功，避免盲目新增。远端被手工修改时展示比较，作者决定保留、复制或覆盖。上传素材后、真正更新草稿前会再读回比较；微信接口没有原子比较后写入能力，两次网络调用之间仍有短暂竞态。同步期间的新输入不会被旧快照替换。

## 技术写作与局部排版

技术写作提供教程、实测报告和 ROCm 转载结构、三个标题候选和实验条件表。只做静态检查，不执行文章命令，不自动编造性能结论。

预览中的“写作工具”提供可搜索大纲、代码折叠、专注模式、分栏宽度和三类个人预设。点击预览块可调整受控字号与间距；设置随稿保存。源码变化后无法可靠对应的覆盖会提示重新选择，不按旧位置误套用。

公式与 Mermaid 组件均本地加载；发布时仅图表子节点转换为 PNG，源代码与图表源码继续保留。脚本、外部图像、动态公式扩展与不安全图表指令被拒绝。

## 验收边界

合成浏览器矩阵覆盖普通手机、折叠屏内外屏和 iPad 宽度。它不代表真实微信内核验收。iOS/Android 微信草稿中的行距、长代码、宽表、图注与深色模式仍需要真机检查。网络模式按本机配置生效：系统网络模式依赖公众号 IP 白名单，公司直连严格模式会在出口未匹配时停止微信请求。
