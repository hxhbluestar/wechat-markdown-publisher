# 微信代码格式修复验收 · 2026-10-22

版本：`2026.10.22-presentation.1`。

- 修复代码换行只依赖 `white-space` 样式的问题：导出实际 `<br>`，行首原始空格和 Tab 包在具有显示宽度的缩进元素中，保留代码原始字符与语法高亮。

- 排版版本已递增，旧同步稿件会提示重新检查并同步。更新程序不自动向公众号提交草稿。
