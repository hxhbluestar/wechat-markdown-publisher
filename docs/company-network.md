# 固定公网出口模式

默认系统模式由 Python urllib 使用系统或环境代理配置。Windows 的公司直连模式使用独立 HTTPS 连接，绑定物理网卡及源 IPv4，保留证书校验，并在每次微信 API 请求前检查公网出口。JSON 请求和图片上传均受保护，缓存 token 不跳过检查。

将 `config/company-network.example.json` 复制到自己的运行数据目录，填写真实的固定公网 IPv4、物理网卡名和内网网关；可额外填写网卡 GUID。不要直接使用未填写的示例值。

源码启动示例：

```powershell
$env:WECHAT_NETWORK_CONFIG = 'C:\publisher-data\private\company-network.json'
python app/web/server.py
```

编辑器底部显示模式、要求出口和探测结果；“检查出口”只进行网络预检，不发送账号凭据或发布文章。显式配置 `{"mode":"system"}` 可选择系统模式；固定出口配置损坏或丢失时停止微信请求。

公司直连绕过应用层代理，拒绝重定向、内网/fake-IP DNS 地址和非预期目标。网卡、网关或出口不匹配时停止，不自动切换代理或其他网卡。请勿将公网出口地址当成本地网关。

公网探测结果只说明探测服务所见的出口。公司路由器若针对不同目的地址选择 WAN/NAT，微信可能看到不同地址；VPN 的内核过滤器也可能阻断流量。确保稳定的微信出口仍需正确配置公司网关的策略路由与 SNAT，并结合微信官方接口或路由器会话记录核对。离开公司时，必须有回到该固定出口的可用通道。
